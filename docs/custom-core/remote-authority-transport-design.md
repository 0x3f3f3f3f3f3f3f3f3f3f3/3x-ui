## Chosen boundary

Expose six typed POST operations under the existing verified HTTPS/admin-node-sync/verified-mTLS/session-CSRF32KiB chain: demand requests, install, get, pause, seal and renew. Reuse core private authority methods, never relay arbitrary core RPC. Before and after every RPC, retain lifecycle ownership, SQL connection admission and the exact process/private-socket/current-boot/journal-pinned delegated role. Require both expected stable source and boot, plus the exact coordinator authority/generation/node tuple. Local owners refuse remote grant operations. Restart/restore/changed role/socket/busy/canceled requests fail safely.

Each request has exact unique non-null fields and typed payloads. Nested grant/binding/directional-share/renewal data must reject duplicate/escaped aliases/case aliases/null/unknown/trailing data before core mutation. Preserve exact uint64 values; no float conversion. Validate outer and inner source/boot/client/grant identities agree. The core retains challenge consumption, grant replay/sequence, policy/window, duration/rate/capacity checks. Server/client responses remain bounded and validate full requested identities, usage and grant sequence; errors never release uncertain coordinator capacity.

Reuse DiscoverAuthority for fresh challenge/current-role discovery. Add a pinned typed RemoteAuthorityAPI adapter compatible with existing authorityDemandAPI: Capabilities returns cloned immutable metadata; BindAuthority verifies the already configured durable role/current boot rather than enabling arbitrary rebinding. Every operation sends the pinned expected identities, uses verified direct TLS/encrypted stored node tokens and rejects redirects. No local allocation controller starts at the node.

## Canonical wire contract and completion boundary

Outer control envelopes contain one required `binding` object with exact camelCase expectedInstanceId, expectedBootId, authorityId, generation, nodeId, plus operation fields/payload. Generation retains the existing role/setup integer contract and its1..MaxInt64 bound. Typed protobuf operation payloads and results use only canonical protobuf JSON camelCase names; uint64 fields are canonical quoted decimal strings, preserving exact values across Go and JavaScript. Reject legacy snake_case aliases, duplicate or escaped duplicate keys, null, unknown fields, exponents, signs, leading zeros and numeric rather than string uint64 payloads before protobuf decoding. Emit default scalar values and empty request arrays explicitly. Typed internal service values stay protobuf pointers; bounded wire helpers perform the translation without arbitrary RPC forwarding. Capabilities/discovery keep their existing schema for compatibility.

Demand long polling is bounded to at most128 requests and the existing core one-second wait; admission holds lifecycle ownership only for the bounded call. A busy owner fails rather than queues a mutation across restart. Renew success acknowledges the exact submitted renewal identity/sequence/duration; it does not claim returned usage or a new allocation. Existing adapter Bind/Enable methods validate pinned current discovery and the configured tuple; they cannot send a new bind operation. Service returns copied execution-role metadata and cloned protobuf results after the second ownership proof. Any uncertain error after mutation stays an error and cannot authorize coordinator capacity reuse.

This phase proves a real independently issued journal allocation executes over HTTPS, including literal2x Tunnel accounting and bounded admission. It does not yet present node-local SQL totals as the global source of truth, automatically remap client UUIDs, or support converting already consumed local sources. Those are explicit following product tasks, with original full-project completion still required.

## Public operations

Six POST routes beneath `/panel/api/server/clientPolicyAuthority/`: `requests`, `install`, `get`, `pause`, `seal`, `renew`. Discovery and durable setup retain their existing routes. Service and Remote expose distinct typed methods; shared admission is an implementation detail, not a user-supplied operation/RPC name. Typed result identities contain instanceId, bootId and executionRole; requests returns a bounded request page, install/get/pause/seal return a complete execution grant state, and renew echoes the accepted renewal identity/sequence/duration. All failures remain opaque at the production HTTP boundary.
